This project implements a patient record management system for three simulated hospital facilities using self-built array-based data structures in C++ — no built-in STL containers (vector, list, etc.) were used. Each facility's dataset is managed with a different array design: a fixed-size array, a dynamically resizing array, and a sorted-on-insert array, allowing comparison of insertion, sorting, and searching performance across approaches. The system implements multiple sorting algorithms (Bubble Sort, Counting Sort, Insertion Sort, and Merge Sort) and both Linear and Binary Search, with execution time measured using <chrono> for performance analysis.
